**GERENCIAMENTO DE BUILD**

Build é o codigo fonte do programa e transformar aquilo em algo executável.
Uma ferramenta que automatiza e organiza todo o processo de build de um projeto Java (ou outros). Com ela, você define o que precisa ser feito e o gerenciador cuida da execução.
 * Maven e Gradle, são os principais e unicos gerenciadores de builds.
 * Maven: O Maven é uma ferramenta tradicional e muito usada no mercado corporativo. Ele segue o princípio da "convenção sobre configuração", ou seja, usa uma estrutura de pastas padrão e arquivos XML para definir como o projeto deve ser construído.
 * Gradle: O Gradle é uma ferramenta mais moderna e flexível. Ele usa scripts escritos em Groovy (ou Kotlin) no arquivo build.gradle. Por ser baseado em scripts e não em XML, o Gradle permite uma configuração mais personalizada e expressiva.
